Privacy Policy

Last updated: November 17, 2026

Alpha Agents is a private tool used by its owner to manage the owner's own YouTube channels. It is not offered to the public.

What data it uses

When the owner signs in with Google, Alpha Agents receives access to the owner's YouTube account through the YouTube Data API and YouTube Analytics API. It uses that access only to:

  • upload videos the owner has approved to the owner's channels, and
  • read the channels' public statistics (views, subscribers, likes, comments) and analytics.

Where data is kept

Sign-in tokens and statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Alpha Agents' use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. YouTube features are subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time from Google Account permissions. Locally stored data can be deleted by the owner at any time.
